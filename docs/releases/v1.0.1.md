## Installation truth

- Use the default `.zip` for ChatGPT web / Cloud Work.
- Use the default `.skill` for the documented desktop flow.
- Use the `-full` archive only when source-resolution pixels are required.
- Install desktop and web separately; OpenAI does not treat one as proof of the
  other.

Public release download verification, Codex refresh, and a fresh ChatGPT web /
Cloud Work invocation are required release gates, not assumptions from a local
build.
