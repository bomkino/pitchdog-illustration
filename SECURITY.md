# Security and privacy

Report private-data leakage, malicious skill instructions, archive traversal,
unsafe executable content, rights-boundary errors, or supply-chain issues
through GitHub's private security-advisory flow for this repository.

Do not open a public issue containing a real family photograph, private path,
account identifier, generation prompt with confidential material, or other
sensitive evidence. Describe the affected file and impact privately.

The release validator rejects symlinks, path traversal, hidden junk, executable
or font binaries, Git LFS pointers, private absolute paths, common secret
patterns, and unmanifested reference files. A clean static scan does not prove
that every depicted person's publicity or personality rights are cleared for
every jurisdiction; see [NOTICE.md](NOTICE.md).
